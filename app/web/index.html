标签索引

标签精确检索（?tag=）依赖的倒排表 · 未建完时客户端不启用该能力 -
同步入库时会增量维护；升级后启动时自动补齐（可断点续跑）。完建前 /healthz 不声明 tag_search，客户端继续用名称模糊检索 —— 两边都不需要回滚。

计划任务

后台定时任务（源站刷新 / 增量同步 / 数据维护 / 相关校准 / 字段回填 / 明星Tag重建），可暂停、恢复、立即执行或改周期
这里的周期来自服务配置（环境变量）；改周期只影响本次运行，重启后会回到配置值。 任务被暂停后不再触发，但「立即执行」仍可手动跑一次。数据维护 / 字段回填默认可能未启用。

去广告规则包

客户端 m3u8 广告过滤的阈值与 URL 模式 · 过滤在端上执行，服务端只下发规则与收上报 -
发布前服务端按客户端钳制区间校验，越界直接拒绝（客户端对越界包的处理是整体丢弃回退内置规则，不会「按钳制值跑」）： relative_max_ratio 0.05~0.95 · absolute_max_sec 10~1800 · safety_floor 0.5~1.0 · safety_floor_high_confidence 0.4~1.0（v1.5.169 高置信安全钳）· duplicate_max_ratio 0.3~0.9（v1.5.169 重复插入上限）· url_patterns ≤64 条（每项 ≤64 字符）· site_overrides ≤256 条（mode 目前只支持 off）。 字段缺省 = 客户端用自己的内置默认值。
